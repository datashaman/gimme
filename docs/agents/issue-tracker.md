# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues under
`datashaman/gimme`. Use the `gh` CLI for all operations.

## Conventions

- Create issues with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List issues with `gh issue list`, requesting structured JSON when processing results.
- Comment with `gh issue comment <number>`.
- Apply or remove labels with `gh issue edit`.
- Close issues with `gh issue close`, including a closeout comment when appropriate.
- Run commands from this repository so `gh` resolves `datashaman/gimme` from the Git remote.

## Skill terminology

When a skill says “publish to the issue tracker,” create a GitHub issue.

When a skill says “fetch the relevant ticket,” read the full GitHub issue body,
labels, and comments.
